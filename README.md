# Tangkap Bintang ⭐

Game anak berbasis web untuk desktop dan mobile.

## Fitur
- Karakter yang bisa diganti: Bimo, Lala, Mimi, Bunny
- 4 dunia: Langit Ceria, Hutan Ajaib, Laut Pelangi, Ruang Angkasa
- 12 level dengan kecepatan yang meningkat
- Koin, nyawa, waktu, streak, power-up Magnet dan Rainbow
- Efek suara berbasis Web Audio
- Leaderboard lokal top 5 dan rekor terbaik
- Sistem hadiah berdasarkan pencapaian
- Pause/resume
- Responsive untuk HP dan desktop
- GitHub Pages deployment lewat GitHub Actions

## Menjalankan
Buka `index.html` atau host isi repository di GitHub Pages.
